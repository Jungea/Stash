# Stash

보고 싶은 링크를 휴대폰에서 바로 저장하고, 폴더로 정리해 두는 나만의 링크 보관함입니다.

## 이런 걸 할 수 있어요

- **공유 버튼 한 번으로 저장**: 브라우저, 유튜브, SNS 등 어떤 앱에서든 "공유"를 누르고 Stash를 고르면 저장돼요.
- **제목과 대표 사진이 자동으로 채워져요**: 링크만 넣으면 알아서 가져와요.
- **폴더로 정리**: 폴더를 만들고, 폴더 안에 또 폴더를 만들 수 있어요. 폴더마다 색도 정할 수 있어요.
- **즐겨찾기와 메모**: 자주 보는 링크는 즐겨찾기로 위에 모아 두고, 메모도 남길 수 있어요.
- **검색**: 제목, 주소, 메모, 설명에서 찾아줘요.
- **나만 볼 수 있어요**: 로그인해야만 열리고, 검색 사이트에도 나오지 않아요.

## 휴대폰에 설치하기 (Android)

앱스토어 설치 없이, 크롬에서 바로 앱처럼 설치할 수 있어요.

1. 크롬에서 Stash 주소(`stash.kro.kr`)로 들어가 로그인해요.
2. 오른쪽 위 메뉴(⋮)에서 **"홈 화면에 추가"** 를 눌러요.
3. 홈 화면에 Stash 아이콘이 생기고, 다른 앱의 공유 목록에도 Stash가 나타나요.

> 설치를 해야 공유 목록에 Stash가 보여요.

## 사용 방법

### 링크 저장하기

- **공유로 저장**: 저장하고 싶은 페이지에서 공유 → **Stash** 선택 → 이름, 설명, 폴더를 확인하고 저장.
- **직접 추가**: Stash 화면의 추가 버튼 → 주소를 붙여 넣고 저장.

### 정리하기

- 링크 카드의 메뉴(⋯)에서 수정, 삭제, 폴더 이동을 할 수 있어요.
- 별 모양으로 즐겨찾기를 켜고 끌 수 있어요.
- 폴더는 폴더 관리 화면에서 만들고, 이름과 색을 바꾸고, 끌어서 순서를 바꿔요.

### 찾아보기

- 위쪽 검색창에 단어를 입력해요.
- 폴더, 태그, 즐겨찾기로 걸러서 볼 수 있어요.
- 정렬은 최신순 / 이름순 중에서 고르고, 즐겨찾기를 맨 위에 고정할 수도 있어요.

## 자주 묻는 질문

**공유했는데 저장이 안 돼요.**
로그인이 풀렸을 수 있어요. Stash 앱을 열어 다시 로그인한 뒤 공유해 보세요.

**공유 목록에 Stash가 안 보여요.**
"홈 화면에 추가"로 설치했는지 확인해 주세요. 설치 후에도 안 보이면 앱을 한 번 열었다가 다시 공유해 보세요.

**다른 사람이 제 링크를 볼 수 있나요?**
아니요. 로그인한 본인 계정의 링크만 보여요. 계정은 관리자가 직접 만들어 주는 방식이라, 따로 가입 화면은 없어요.

**제목이나 사진이 안 나오는 링크가 있어요.**
사이트에 따라 정보를 가져오지 못할 수 있어요. 이럴 땐 링크 수정에서 제목을 직접 적어 주세요.
