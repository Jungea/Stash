## 작업 로그

### [1] Next.js 프로젝트 초기화 (개발 순서 1번)
- Next.js (App Router, TypeScript) + Tailwind CSS 프로젝트 생성
- 추가 패키지 설치: `@supabase/supabase-js`, `jose`, `cheerio`
- 위치: /home/jea/projects/Stash (기존 폴더 내 직접 생성)
- 완료: Next.js 16.3.1 + React 19 + Tailwind 4 + TypeScript 5
- 추가 설치: @supabase/supabase-js ^2, jose ^6, cheerio ^1
- package.json name 수정 (stash-tmp → stash)

### [2] Supabase 스키마 작성 (개발 순서 2번)
- `supabase/schema.sql` 생성: folders, links, tags, link_tags 테이블
- updated_at 자동 갱신 트리거 추가 (set_updated_at)
- 모든 테이블 RLS 활성화 (anon 차단, service_role로 우회)
- `.env.local.example` 템플릿 생성
- 수동 작업: Supabase 콘솔 SQL Editor에서 schema.sql 실행 필요

### [3] lib/auth.ts, lib/supabase.ts 작성 (개발 순서 3번)
- `lib/supabase.ts`: service_role 키 사용 Supabase 클라이언트 (RLS 우회, 서버 전용)
- `lib/auth.ts`: verifyPassword (상수시간 비교), signToken (JWT HS256 30일), verifyToken, SESSION_COOKIE 상수

### [4] middleware.ts 인증 가드 (개발 순서 4번)
- 공개 경로: /login, /api/auth/login, /api/auth/logout, /manifest.json, /robots.txt
- 정적 파일·아이콘·확장자 포함 경로 자동 통과
- 인증 실패 시: API → 401 JSON, 페이지 → /login 리다이렉트

### [5] 로그인 페이지 + 인증 API (개발 순서 5번)
- `app/api/auth/login/route.ts`: POST — 비밀번호 검증 후 httpOnly JWT 쿠키 발급 (30일)
- `app/api/auth/logout/route.ts`: POST — 쿠키 만료 처리
- `app/login/page.tsx`: 비밀번호 입력 폼, 로그인 성공 시 / 리다이렉트
- `app/layout.tsx`: metadata noindex 적용, title "Stash"로 변경

### [6] 공유 API + OG 크롤링 (개발 순서 6번)
- `lib/metadata.ts`: fetchMetadata (cheerio로 og:title/description/image, 파비콘 추출), extractUrl (text에서 URL 정규식 추출)
- `app/api/share/route.ts`: GET — Android 공유하기 수신 후 저장 + / 리다이렉트, POST — 수동 URL 추가

### [7] 링크/폴더/태그 CRUD API (개발 순서 7번)
- `app/api/links/route.ts`: GET — q/folderId/tagId/favorite/sort 쿼리 지원
- `app/api/links/[id]/route.ts`: PATCH (필드 + tagIds 교체), DELETE
- `app/api/folders/route.ts`: GET (전체 목록), POST (생성)
- `app/api/folders/[id]/route.ts`: PATCH (name/parent_id), DELETE
- `app/api/tags/route.ts`: GET (링크 수 포함), POST (upsert)

### [8] 메인 페이지 UI (개발 순서 8번)
- `types/index.ts`: Link, Folder, Tag, FolderNode 공유 타입
- `app/globals.css`: 항상 다크 테마로 고정
- `app/page.tsx`: Server Component, saved 파라미터 감지해 MainView에 전달
- `components/MainView.tsx`: 링크 목록, 검색, 필터, 정렬, 사이드바 상태 관리
- `components/FolderSidebar.tsx`: 재귀 폴더 트리, 태그 목록, 즐겨찾기 필터
- `components/LinkCard.tsx`: 썸네일/파비콘, 즐겨찾기 토글, 읽음/삭제 메뉴
- `components/AddLinkModal.tsx`: URL 입력 + 폴더 선택 모달 (모바일 바텀시트)
- `components/Toast.tsx`: 3초 자동 소멸 토스트

### [9] PWA 설정 (개발 순서 9번)
- `public/manifest.json`: share_target(GET /api/share), 아이콘, 다크 테마 색상
